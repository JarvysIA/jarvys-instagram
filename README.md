# Jarvys: artes do Instagram

Imagens e vídeos públicos do @jarvys.ia, usados pelo agendamento no Buffer.
Os links usados nos posts são do tipo `https://raw.githubusercontent.com/JarvysIA/jarvys-instagram/main/<pasta>/<arquivo>`.

Não apague nem renomeie arquivos de posts agendados: o Buffer busca a mídia na hora de publicar.

- `2026-10/lote2/`: semana de 11 a 17/10/2026 (posts em JPG 1080x1350, reels em MP4 1080x1920).
- `_codigo/`: o código das peças (semanaN.mjs), o render.mjs e o reel.sh usados para gerar as mídias.
